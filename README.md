# Amicale Bouliste Heulinoise — version 4

Cette version 4 :
- garde la structure du site,
- conserve le logo officiel,
- utilise une illustration d'accueil mixant la pétanque et la boule nantaise,
- améliore la présentation de la page d'accueil.

## Fichiers importants
- `index.html` : page d'accueil
- `club.html` : présentation du club
- `actualites.html` : actualités
- `calendrier.html` : agenda
- `resultats.html` : résultats
- `galerie.html` : photos
- `contact.html` : coordonnées
- `style.css` : couleurs et mise en page
- `assets/hero-mix.png` : nouvelle illustration d'accueil

## Pour voir le site correctement
1. Décompresser le ZIP complet.
2. Ouvrir le dossier extrait.
3. Double-cliquer sur `index.html`.

## Suite possible
- ajouter les vraies dates,
- ajouter les vrais résultats,
- remplacer les contenus d'exemple,
- insérer les vraies photos du club.
